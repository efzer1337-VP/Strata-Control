Какие настройки изменятся

Пресет меняет только перечисленные настройки выбранного профиля. Сохраните его вручную; работающий сервер потребует явного перезапуска. Скорость и вместимость модели на этих значениях не измерялись.

Добавьте модель для этого движка

Выберите локальный файл или импортируйте профиль. Настройки других движков хранятся отдельно.

Настройки

Пустые дополнительные поля наследуют значения движка или подготовленной конфигурации. Очистите поле, чтобы убрать своё переопределение. Параметры запроса API могут переопределять генерацию.

Загрузка профилей…

Подходящих настроек нет. Измените поиск или отключите фильтр избранного.

Сервер

Проверяем состояние…

Выбор профиля и сохранение настроек не перезапускают сервер. «Перезапустить» остановит выбранный профиль и запустит его с новыми параметрами.

Команда PowerShell

Предпросмотр текущих настроек. RAM-сторож включается при запуске из Control.

Есть несохранённые изменения
Сохраните текущий профиль перед переходом или отбросьте изменения.


Создать копию профиля
Копия сохранит движок, модель и все параметры. Исходный профиль останется без изменений.


Добавить локальную модель
Веса не скачиваются. Strata подготавливает свой pack; другие движки используют локальные файлы.


Управление движками
Strata и PolyStrata используют локальную установку. Для PolyStrata нужны её сервер, движок и подготовленная конфигурация модели.
