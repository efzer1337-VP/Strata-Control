# Установка Strata Control на Windows

Control помогает установить движок, выбрать модель и управлять её локальным сервером. Эта инструкция предназначена для установки из актуального репозитория.

## Что понадобится

- Windows x86-64, интернет и доступная для записи папка на диске.
- Поддерживаемая видеокарта NVIDIA или AMD с установленным драйвером. Наличие сборки для конкретной карты и движка определяется установщиком; если готового движка для Windows AMD нет, он сообщит об ошибке.
- Свободное место для компонентов и, если вы решите скачать модель, для её файлов и подготовки. Например, Ornith Uncensored Q4_K_M занимает около 21,7 ГБ, Q3_K_M — около 17,2 ГБ; для подготовки потребуется дополнительное место. Объём RAM зависит от модели и настроек.

Python заранее устанавливать не обязательно: установщик использует подходящий Python, а при его отсутствии установит его в папку приложения. Для компонентов и движка интернет нужен даже при отказе от скачивания модели.

## 1. Скачайте и распакуйте

1. [Скачайте репозиторий ZIP-архивом](https://github.com/efzer1337-VP/Strata-Control/archive/refs/heads/main.zip).
2. Распакуйте **весь архив** в любую папку, доступную для записи, например `D:\AI\Strata-Control`. Не запускайте установщик прямо внутри ZIP.
3. Откройте распакованную папку, в которой находятся `INSTALL.bat` и папка `downloads`.

## 2. Установите компоненты

1. Дважды нажмите `INSTALL.bat`. Файл `INSTAL.bat` выполняет ту же установку.
2. В открывшемся окне выберите движок: `1` — Strata, `2` — PolyStrata, `3` — оба. Нажмите Enter после выбора.
3. На вопрос о модели выберите `0` или нажмите Enter, чтобы пропустить загрузку, либо выберите предложенную модель. Для PolyStrata можно выбрать стандартную Ornith или Ornith 1.5 Uncensored и её квантовку. Дальнейшие вопросы зависят от модели; vision предлагается отдельно.
4. Дождитесь сообщения об окончании установки. Установщик откроет Control; модель автоматически не запускается.

Компоненты размещаются внутри распакованной папки: рабочая установка — в `.strata-full\Strata`, модели и подготовленные данные — в `.strata-full\Strata\Strata-data`. Установщик не переносит модели из других установок. Загрузка модели необязательна: её можно выбрать при повторном запуске `INSTALL.bat`.

## 3. Запустите модель

1. Для последующих запусков откройте `START-CONTROL.bat` в распакованной папке.
2. В Control выберите движок и профиль модели. Если при установке модель не скачивали, повторно запустите `INSTALL.bat` и выберите модель либо добавьте совместимый локальный GGUF через **Добавить модель**. Подробности для разных движков приведены в [инструкции Control](CONTROL-QUICKSTART.md#добавление-скачанной-модели).
3. Проверьте настройки и нажмите **Запустить**. Дождитесь готовности сервера в панели. Его адрес API будет показан там же.
4. Для завершения работы модели нажмите **Остановить**. Закрытие окна Control само по себе не останавливает сервер.

Чтобы удалить профиль, выберите его и нажмите **Удалить**, затем подтвердите действие. Сначала остановите сервер этого профиля. Файлы модели и подготовленные данные сохраняются.

## Если возникла ошибка

- **Установщик не находит полный пакет:** распакуйте весь ZIP заново; рядом с `INSTALL.bat` должна быть папка `downloads` с архивом пакета.
- **Видеокарта не обнаружена или драйвер слишком старый:** установите или обновите драйвер производителя и снова запустите установщик. Для конкретного оборудования готовый движок может быть недоступен.
- **Недостаточно места или памяти:** проверьте свободное место на диске и требования выбранной модели. Можно установить компоненты без модели, а модель выбрать позже.
- **Панель или сервер не запускается:** проверьте журнал в Control. Журнал запуска панели находится в `.strata-full\Strata\.strata-control\web-control.log`.

Дополнительные сведения о моделях, настройках, импорте профилей и других движках: [инструкция Control](CONTROL-QUICKSTART.md). Панель и сервер по умолчанию доступны локально; для доступа к API с других устройств настройте ключ по [документации Strata](https://github.com/Niko1221/Strata/blob/main/docs/AI_SETUP.md).
