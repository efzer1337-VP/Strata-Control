# Обновление движка Strata — 23 октября 2026

Установленный `engine/strata.exe` обновлён с **0.1.43 до 0.1.48**. Это версия движка в последнем проверенном официальном [релизе приложения 0.2.3.1](https://github.com/Niko1221/Strata/releases/tag/v0.2.3.1). Номера приложения, его Terminal Control и нативного движка различаются.

Использован официальный пакет `strata-engine-0.1.48-windows-x86_64-cuda-cuda13.tar.gz`, 581299508 байт. SHA-256 архива совпал с GitHub:

```text
1e1611b0977d984bd7d8e79591a1ba1a7e550a2f4a66bfa45744a77308a71b95
```

Также проверены размеры и SHA-256 каждого файла из `engine-component.json`. Установлены основной движок, vision, библиотека KQ и библиотеки cuBLAS. Сборка содержит sm_89 для установленной NVIDIA RTX 4080; драйвер 617.14 удовлетворяет требованию пакета 580.65.

Прежняя папка целиком сохранена в `.strata-control/engine-backups/0.1.43-5be7ccf018224146bce856b18405caa0`. Контрольные суммы её файлов проверены после переноса. Журнал и точные пути: [engine-update.json](../.strata-control/engine-update.json).

## Проверено

- Установленный EXE сообщает `strata 0.1.48`; справка движка и проверка версии vision запускаются.
- Все 19 флагов сохранённого native-профиля найдены в parser новой версии.
- CUDA runtime видит одну GPU; новая cuBLAS создаёт и освобождает GPU-контекст; новая `strata_kq.dll` загружается.
- Текущий Python-сервер с копией реального профиля запущен на временном порту `127.0.0.1` в режиме lazy. `/health` вернул `status: ok`, `loaded: false`; `/v1/models` ответил успешно. Тестовый сервер остановлен.
- Все 8 существующих профилей проходят preflight; открытие и сохранение без правок возвращает исходный JSON. Хеши файлов профилей не изменились.
- 92 теста Control прошли. Резервная копия старого движка проверена; временные архив и фрагменты загрузки удалены.

## Область изменения

Модели, pack, MTP, токенизаторы, профили, PolyStrata и llama.cpp не обновлялись. Наша панель Control остаётся версии 4.3; checkout исходников и Python-сервер сохранены. Путь запуска `engine/strata.exe` прежний, поэтому следующий запуск через панель использует 0.1.48.

В `strata_control_settings.py` уточнена одна подсказка: пустой бюджет кэша бесед наследует выбор установленной версии. У 0.1.48 отсутствие `--conversation-cache-mib` включает автоматический подбор по свободной RAM; у исследованной ранее 0.1.43 кэш без флага был выключен. Явное значение 0 по-прежнему выключает кэш; пресеты остаются явным выбором пользователя.

Полная загрузка модели, генерация токенов, обработка изображения и скорость не проверялись: перед проверкой было доступно около 12.1 ГиБ RAM из 31.9 ГиБ. Проверка API использовала lazy и не загружала веса. CUDA/HIP/SYCL исходники не менялись; установлен готовый официальный пакет Windows CUDA 13.
