# Параметры основного Strata для Control

Первичные источники проекта: [описание параметров](https://github.com/Niko1221/Strata/blob/main/docs/DETAILS.md), [парсер движка](https://github.com/Niko1221/Strata/blob/main/src/program/generate.cpp), [сервер](https://github.com/Niko1221/Strata/blob/main/serve/server.py). ## Что уже есть и чего недостаёт

В [strata_control_web.py](../strata_control_web.py) строки 97–124 и 185–192 основной Strata уже показывает контекст, KV, resident KV, cache экспертов, резидентные эксперты, MTP, spec, запас RAM/VRAM, vision и lazy load. Поля CPU, sampling и reasoning сейчас показываются только внешним движкам, хотя основной сервер поддерживает собственные контракты этих настроек. Расширение должно учитывать, что `--threads` и параметры llama.cpp не являются параметрами Strata.

## Важные поправки к существующим полям

KV Strata поддерживает `fp16`, `int8`, `q4_0`, `k8v4`; `q4` принимается как alias `q4_0` ([generate.cpp](../src/program/generate.cpp):2448–2466). Bare CLI использует fp16. Setup пишет формат из выбранного профиля только при контексте выше 8192 ([setup.py](../setup.py):5571–5580). Поэтому отсутствие `--kv` в старом профиле нельзя отображать как принудительный int8 или превращать в него при сохранении. Текущее поле Control показывает только три квантованных формата.

Полная копия streaming KV находится в RAM, а VRAM содержит выбранные страницы. Память на одну KV ячейку одной QSA layer: fp16 2048 B; int8 1056 B; q4_0 576 B; k8v4 816 B. FP16 рассчитано из 2 KV голов × 256 каналов × K/V × 2 байта; размер явно описан в [kv_q8.hpp](../include/strata/kernels/kv_q8.hpp):8, геометрия в [qsa.hpp](../include/strata/kernels/qsa.hpp):111. Формулы квантованных форматов в [kv_q8.hpp](../include/strata/kernels/kv_q8.hpp):25, [kv_q4.hpp](../include/strata/kernels/kv_q4.hpp):36 и [layer.cpp](../src/core/layer.cpp):652–662. Это размер KV, а не полная потребность модели в RAM.

Streaming fp16 поддержан: [layer.cpp](../src/core/layer.cpp):802–831 создаёт host k_pool/v_pool uint16 для неквантованной ветки. Минимальная фактическая резидентная часть составляет 20480 ячеек ([layer.cpp](../src/core/layer.cpp):648,667), даже если пользователь попросил меньше. 0 выключает streaming. Когда контекст укладывается в resident, streaming не нужен. При расчёте RAM учитывать **полный контекст**, округление страниц, число QSA слоёв и drafter, а не вычитать resident. WSL не подходит для pinned streaming в рекомендуемых конфигурациях ([layer.cpp](../src/core/layer.cpp):808–812).

`--resident-experts` означает low-RAM режим с отображением файлов и копированием CPU-экспертов, не просто «держать все эксперты в RAM»: [generate.cpp](../src/program/generate.cpp):438–451. Сохранить действующий режим выбранной модели, не включать этот флаг общим пресетом без анализа её подготовки и доступной памяти.

MTP необязателен, но требует подготовленный runtime, а его head занимает отдельную VRAM. Существующую модель и runtime пресеты должны сохранять. Нельзя автоматически подменять draft_vocab: это подготовленный двоичный файл, а не безвредное имя режима в CLI. Подмножества en/cjk/cyrillic/fr выбираются в setup, сопровождаются подготовкой файла.

## Sampling и API

Sampling хранится в отдельном объекте `sampling`, а не в args и не в `engine_settings` внешнего движка. Приоритет: config sampling, затем shared Chat settings, затем явно переданное значение запроса ([server.py](../serve/server.py):3676). Пустое поле должно убирать только свой override и сохранять остальные ключи объекта. Если объект стал пуст, его можно удалить. Не переносить и не активировать Chat или Harness для настройки этих defaults.

Сервер также поддерживает `sampling.presence_penalty >= 0`, `frequency_penalty >= 0`, `repetition_penalty > 0` (1 выключает), `penalty_last_n` целое >= 0 и seed целое > 0. Alias `repeat_penalty` / `repeat_last_n` соответствует двум последним каноническим ключам, но одновременное указание alias и канонического имени вызывает ошибку запуска. Полезно оставить эти поля в расширенной группе. Опорный код: [server.py](../serve/server.py):5992–6052. Для всех новых чисел Control должен дополнительно отклонять NaN и Infinity: не все старые серверные проверки делают это явно.

Reasoning и budget применяются к запросам API. Уровень является инструкцией модели, а token budget является жёстким ограничением до закрытия think. У Anthropic `thinking.budget_tokens` прежде всего выбирает уровень; собственный `reasoning_budget_tokens` ограничивает число токенов. [DETAILS.md](DETAILS.md):712–740 описывает различие. Для Strata нельзя использовать значения бюджета llama.cpp `-1/0` с прежними подписями.

## Backend и оборудование

Bare `--prefill auto` сохраняет платформенные защитные правила: на Windows HIP потолок 6144; gfx12 Linux может повысить его до 16384. Явный `auto:N` или число отменяет часть автоматических защит, поэтому расширенные значения не включать в универсальный пресет. [generate.cpp](../src/program/generate.cpp):1952–1969, 2162–2173. Большой chunk не означает гарантированную скорость: setup отдельно предупреждает о `auto:32768` на небольшом объёме RAM ([setup.py](../setup.py):4547–4575).

Параллельность резервирует сессию каждого слота до размера expert cache, может уменьшить cache экспертов и не означает сокращение задержки одного запроса. Основные gates и объяснение от движка: [generate.cpp](../src/program/generate.cpp):4298–4423. `--batch-mtp` требует MTP и spec >= 2, отдельную память на drafter, не сочетается с pipelined batch groups; оставить в дополнительных аргументах.

`--vram-elastic` поддерживается как отдельная opt-in возможность NVIDIA, требует соответствующую сборку, не является универсальной настройкой HIP/SYCL. Числа PCIe share, async adaptive tier, fused-kernel env, route-tail skip, rope/yarn за пределами нативного контекста, IQ-specific env и ручная CPU affinity не включать в общие стартовые пресеты. Это отдельные эксперименты/возможности модели и оборудования. Не обещать их ускорение без проверки на конкретной машине.

## Три предлагаемых стартовых пресета

Это **рекомендации исследования**, а не заявление о финальном интерфейсе или доказанной производительности. Пресеты выбираются явно, меняют только черновик профиля; пользователь видит diff и сохраняет. На открытии Control ни один пресет не применяется. Сохранить пути модели, pack/profile, MTP, vision, сеть и персональные переменные окружения. Не менять рабочие defaults существующих профилей.

| Название | Набор значений | Основание и ограничения |
| --- | --- | --- |
| Повседневный 32K | context 32768; KV int8; prefill auto; pool-workers 0; prompt-cache 6; every 16384; conversation-cache-mib 0; parallel 1; reasoning effort low; budget 4096; sampling temperature 0, top_p 0.95, top_k 20, min_p 0 | Небольшой заданный контекст, один пользователь, greedy и явный ограниченный thinking. Значения sampling/effort являются выбранным поведением, их не следует описывать как более правильные для всех задач. |
| Длинный контекст 128K | context 131072; KV int8; resident KV 32768; prefill auto; pool-workers 0; prompt-cache 6; every 16384; conversation-cache-mib 0; parallel 1; reasoning effort high; budget 8192 | Setup использует resident KV для больших контекстов, когда хватает RAM. На WSL этот preset должен не включать streaming. Нужны проверки памяти выбранной модели; 128K не гарантируется на каждом ПК. |
| Несколько бесед 32K | context 32768; KV int8; prefill auto; pool-workers 0; prompt-cache 6; every 16384; conversation-cache-mib 2048; slots 4; min-free-mib 2560; parallel 1; reasoning effort medium; budget 4096 | Отдельный RAM budget для чередующихся бесед без VRAM сессий batch. 2048 MiB является стартовым лимитом, а не утверждением, что четыре беседы любого размера поместятся. При недостатке RAM движок пропускает парковку. |

Для третьего пресета не включать parallel 2 автоматически: cache бесед и continuous batching решают разные задачи. Объём RAM budget лучше показывать рядом с доступной RAM и защитным резервом Control. 8 GiB в примере документации не является требованием к каждой машине ([DETAILS.md](DETAILS.md):951–995).

## Проверки реализации

- Открытие и сохранение без изменений не добавляет отсутствующие CLI/JSON defaults и сохраняет весь исходный config.
- Пустое значение удаляет только принадлежащий ему override; неизвестные и аппаратные параметры остаются неизменны.
- Значения из дополнительных аргументов мигрируют в поля без дублирования, поддерживаются `--flag value` и уже поддерживаемая приложением форма `--flag=value`.
- `--batch`/`--slots` не оставляет скрытый конфликт с JSON parallel; source of truth виден пользователю.
- Не передавать `--threads`, `--temperature`, `--reasoning-effort`, `--idle-unload` в args нативного движка Strata, если контракт выше требует другой флаг или JSON ключ.
- Проверить диапазоны, конечность чисел, 0 special values и наследование, отдельно от llama.cpp/PolyStrata.
- Проверить streaming estimate с fp16 2048 B/cell и полным контекстом, minimum resident 20480 и отдельным drafter.
- Применение пресета не запускает, не выгружает и не перезапускает модель; только штатное сохранение/явный запуск изменяют runtime.
- Эта работа не проверяет скорость генерации, реальную VRAM вместимость или runtime CUDA/HIP/SYCL. Такие утверждения требуют измерений на указанной машине.
