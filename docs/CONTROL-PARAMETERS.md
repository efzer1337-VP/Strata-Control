Приоритет имеют исходники установленной версии и справка установленного EXE. Ветка main сверена как внешний первичный источник, но не заменяет установленный контракт.

## Добавленные группы

| Группа | Strata | PolyStrata |
| --- | --- | --- |
| CPU и чтение промпта | `--pool-workers`, `--prefill` | `--threads` с 0 auto, `--prompt-batch` |
| Буферы и черновики | Прежние MTP runtime и spec сохранены | `--stage-mib`, `--stage-ahead`, `--lookup`, `--no-draft`, `--kv-whole` |
| Кэш | Точки промпта и интервал; RAM-бюджет, слоты и порог свободной RAM для бесед | Точки промпта и интервал поверх подготовленного JSON; прежний RAM-бюджет бесед |
| Генерация | JSON `sampling`: temperature, top_p, top_k, min_p, repetition/presence/frequency penalties, penalty_last_n, seed | Те же поля server sampling, overlays поверх исходного runtime |
| Размышление | JSON reasoning_effort и reasoning_budget_tokens | Те же ключи server JSON, без ложных native CLI флагов |
| Сервер | idle_unload_s, engine_silence_s, min_free_vram_mib, parallel | idle_unload_s, engine_silence_s, min_free_vram_mib |

С учётом прежних настроек панель показывает 42 поля для Strata и 36 для PolyStrata. llama.cpp и пользовательские EXE сохраняют свои поля; пресеты Strata к ним не применяются.

Новые параметры необязательны. Пустое поле означает отсутствие override, а не число 0. Для PolyStrata оно наследует подготовленный JSON или модельные defaults сервера. У переключателей три состояния: по умолчанию, включено, выключено. Явные sampling-параметры запроса API имеют приоритет; общие настройки отдельной страницы Strata тоже могут влиять на defaults.

Нулевой бюджет размышления не ограничивает thinking; effort `none` отключает его. Threads 0 выбирает потоки автоматически, idle_unload_s 0 не выгружает модель. Подсказки описывают смысл конкретного поля.

## Три пресета

До применения можно раскрыть список значений «до → после». Кнопка «Применить к черновику» не сохраняет файл и не вызывает start/stop/restart.

Общие значения: запас VRAM 2 ГиБ, резерв RAM `min(8, RAM_ГиБ / 4)`. При временно неизвестной RAM предлагается резерв 4 ГиБ; это рекомендация, не показание оборудования. Вместимость весов и буферов не гарантируется. Проверка резервов и RAM-сторож остаются отдельными механизмами.

| Пресет | Strata | PolyStrata |
| --- | --- | --- |
| С запасом памяти | Контекст 32768; int8 KV; resident KV 0; auto expert cache; кэш бесед 0; parallel 1 | Контекст 32768; fp16 KV; кэш бесед 0 |
| Несколько клиентов | Контекст 32768; RAM-кэш до 2048 МиБ; 4 слота; порог свободной RAM 2560 МиБ; 6 точек промпта с интервалом 16384; parallel 1 | Контекст 32768; RAM-кэш до 2048 МиБ; 6 точек промпта с интервалом 2048; fp16 KV |
| Длинный контекст | Контекст 131072; int8 KV; resident KV 32768; кэш бесед 0; parallel 1 | Контекст 131072; fp16 KV; кэш бесед 0 |

Бюджет кэша «Несколько клиентов»: `min(2048, floor(RAM_ГиБ * 64))` МиБ, то есть не более 1/16 установленной RAM и не более 2 ГиБ. При неизвестной RAM предлагается 1024 МиБ. Четыре слота не гарантируют, что четыре длинные беседы поместятся. Парковка бесед не включает параллельное выполнение.

Streaming Strata хранит **весь** KV в RAM и только резидентное окно в VRAM. Ненулевой размер движок поднимает минимум до 20480 токенов. В WSL пресет длинного контекста не включает streaming. PolyStrata не получает параметры streaming основного Strata; q8_0 KV не включается ни одним пресетом автоматически.

Пресеты не меняют sampling, reasoning, пути модели/pack/tokenizer, Poly JSON, порт, MTP, vision и окружение. Модельные defaults не заменяются универсальными рекомендациями. Ограничения RAM, VRAM и контекста необходимо проверять для конкретной модели. Экспериментальные PCIe, kernels, affinity и steering не включены в пресеты.

## Исправленные контракты

- Strata использует `--pool-workers`, не llama.cpp `--threads`. Если `--kv` отсутствует, native default fp16. Добавлены fp16 и streaming-оценка 2048 B/ячейку; alias q4 отображается как q4_0 без записи файла. Отсутствующие max-context, spec и spec-min-p показывают bare CLI значения 4096, 0 и 0. Явные значения setup сохранены.
- Poly window: 0..8, не 1..16. 0 означает auto, 1 без guesses. Поддержаны threads 0 и native context от 16; верхняя граница Control остаётся 1048576. Server Top K: 1..64, не llama.cpp 0..1000.
- Poly q8_0 KV допускается только qwen35moe с `(n_kv * head_dim) % 32 == 0`. Для заведомо неподдерживаемого GGUF вариант скрыт, сохранённый q8_0 отклоняется до запуска. При нечитаемом заголовке совместимость не обещается.
- Poly sampling наследуется; overlays сохраняют неизвестные ключи и снимают соответствующие aliases repeat_penalty/repeat_last_n при явном canonical override.
- Старые raw --batch/--slots отображаются с настоящим приоритетом. Правка/очистка снимает raw override; no-op сохраняет native batch-MTP значения, включая значения за пределами нового JSON UI диапазона 1..8.

## Сохранение и проверки

Схема: [strata_control_settings.py](../strata_control_settings.py). Пресеты: [strata_control_presets.py](../strata_control_presets.py). Новая настройка меняет только собственный аргумент или JSON ключ. Правка старого поля сохраняет новые и неизвестные аргументы. Обрабатываются дубликаты и формы `--flag value` / `--flag=value`; конфликтующий ручной ввод отклоняется. Импорт проверяет существующие значения. Целые не округляются через float; большие значения проходят через браузер строкой, сохраняя точность.

```text
.venv/Scripts/python.exe -m unittest tools.test_strata_control_settings tools.test_strata_control_parameters tools.test_strata_control_web tools.test_strata_control_poly tools.test_strata_control_memory
node --check serve/control/control.js
```

Все 92 Python-теста прошли. Проверки компиляции Python и синтаксиса JavaScript прошли.

Браузерный сценарий с временными профилями прошёл: все три пресета меняют только черновик, сохранённый export и список операций неизменны, sampling/reasoning сохраняются. Проверены точность большого seed, Cancel/Discard, изоляция движков, импорт/экспорт, клавиатура, пустое состояние и окно 390 px. Ошибок JavaScript нет.

Все 8 реальных профилей проходят read-only preflight и сравнение `updated(profile, field_values(profile)) == profile`; файлы не менялись. Тест запуска использует только маленький HTTP-процесс на CPU, без модели.

Генерация/vision на GPU, скорость, качество и фактическая память при пресетах, загрузка моделей, WSL runtime и Linux не проверены. C++/CUDA/HIP/SYCL исходники не менялись, сборки не выполнялись.
