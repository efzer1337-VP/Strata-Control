# Strata Control — полный комплект

**[Скачать установочный ZIP v3](downloads/Strata-Control-Full-20261022-v3.zip)** · [SHA-256](downloads/Strata-Control-Full-20261022-v3.zip.sha256)

Архив содержит исходники [Strata](https://github.com/Niko1221/Strata) и обновлённый Strata Control. Веса моделей, локальные профили, виртуальное окружение Python и собранные под конкретный ПК движки в GitHub не загружаются.

## Установка

1. Скачайте ZIP v3 и распакуйте его целиком. Либо скачайте этот репозиторий через **Code → Download ZIP**.
2. Запустите `INSTALL.bat`. При установке из репозитория он сначала распакует вложенный полный архив в `.strata-full/`. Установщик Strata подготовит Python, зависимости и предложит модель.
3. Для запуска окна используйте `START-CONTROL.bat` или ярлык Strata Control. Выберите профиль и нажмите «Запустить».

Для работы нужны Windows, совместимый GPU и свободное место под модель. Сервер по умолчанию слушает только `127.0.0.1`. Если открываете его вне локального компьютера, задайте API-ключ согласно [инструкции Strata](https://github.com/Niko1221/Strata/blob/main/docs/AI_SETUP.md).

## Что появилось в v3

- Настольная вкладка **Чат и API**: сообщения, изображения и показатели RAM, VRAM, нагрузки, температуры и мощности GPU, числа токенов и скорости ответа без отдельного браузера.
- Выбор движка: Strata, официальный llama.cpp, а также установленный локально PolyStrata. Для каждого сохраняются собственные параметры. У PolyStrata доступны контекст, память, потоки CPU, KV, MTP, vision и параметры генерации.
- Профили для Ornith 1.5 Uncensored поддерживают [Q4/Q3 GGUF и mmproj](https://huggingface.co/dealignai/Ornith-1.5-35B-A3B-UNCENSORED-GGUF). **Файлы модели и vision нужно скачать отдельно**; локальные пути из компьютера автора в архив не входят.
- Автоматическое обнаружение [PolyStrata](https://github.com/VecSzn/PolyStrata), если его движок установлен в `Strata-data/polystrata`. Сам движок PolyStrata в ZIP не включён. Обычный путь Strata сохраняет прежнее поведение.
- Отдельные профили, настройка памяти, запуск и остановка API; штатные инструменты и исходники Strata сохранены.

На ПК с Ryzen 9 5950X, 32 ГиБ RAM и RTX 4080 16 ГиБ Q4 на llama.cpp оставлял 13,6–14,6 ГиБ свободной RAM после загрузки. PolyStrata Q3 ответил на локальный запрос из 1490 входных и 256 выходных токенов за 3,9 с, оставив около 3,5 ГиБ RAM. Это замеры только на указанной машине, не обещание скорости на другом ПК. Подробности: [ORNITH-SETUP.md](ORNITH-SETUP.md).

## Состав и проверка

Полный архив собран поверх исходников Strata ревизии `7695859aa13afb248bdb4d36f9b2e95707db079d`, указанной в [UPSTREAM.json](UPSTREAM.json). Лицензия MIT и уведомления исходного проекта сохранены. Исходники Control доступны также в корне этого репозитория.

На машине разработки проверены API llama.cpp и PolyStrata, текстовый и зрительный запросы, чат в настольном окне и 14 автоматических тестов. Установка на другом ПК и качество моделей на длительных задачах не проверялись.
