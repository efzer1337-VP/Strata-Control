# Strata Control 4.3

Панель для выбора движка и модели, настройки профилей, управления сервером и наблюдения за ресурсами ПК.

**[Скачать Windows/NVIDIA с движком Strata 0.1.48](https://github.com/efzer1337-VP/Strata-Control/releases/download/v4.3.0/Strata-Control-4.3.0-Windows-NVIDIA-CUDA13.zip)** · [SHA-256](https://github.com/efzer1337-VP/Strata-Control/releases/download/v4.3.0/Strata-Control-4.3.0-Windows-NVIDIA-CUDA13.zip.sha256) · [Релиз](https://github.com/efzer1337-VP/Strata-Control/releases/tag/v4.3.0)

Пакет содержит Control 4.3, исходники установщика Strata и официальный движок **0.1.48** из [релиза Strata 0.2.3.1](https://github.com/Niko1221/Strata/releases/tag/v0.2.3.1), включая vision и библиотеки CUDA. Сборка рассчитана на Windows x86-64, NVIDIA RTX 20/30/40/50 и драйвер от 580.65. Файлы моделей, локальные профили, Python-окружение и резервные копии пользователя не включены.

## Установка и запуск

1. Скачайте основной ZIP по ссылке выше и распакуйте его целиком.
2. Запустите `INSTALL.bat`: установщик подготовит Python и предложит выбрать модель. Веса загружаются отдельно; для них нужно свободное место.
3. Откройте `START-CONTROL.bat`, выберите движок и профиль. Сохранение параметров и перезапуск сервера выполняются отдельными кнопками.

Если Strata уже установлена, можно перенести обновлённые файлы Control в её папку. Сохраните собственные профили, `.venv`, модели и подготовленные данные. Источники Control доступны в корне этого репозитория.

Для других GPU и сборки из исходников доступен [полный пакет исходников 4.3](downloads/Strata-Control-Full-20261023-v4.3.zip) ([SHA-256](downloads/Strata-Control-Full-20261023-v4.3.zip.sha256)). Он не содержит готового движка; его выбирает установщик базовой ревизии Strata. При скачивании через **Code → Download ZIP** корневой `INSTALL.bat` распаковывает этот пакет в `.strata-full/`. Основной Windows/NVIDIA ZIP уже включает движок 0.1.48.

## Изменения в 4.3

- Strata и PolyStrata выбираются постоянными кнопками на главном экране. Профили и параметры каждого движка разделены; llama.cpp и пользовательские EXE доступны отдельно.
- Добавлены поля CPU, чтения промпта, кэша бесед, sampling, reasoning и таймаутов. Пустое дополнительное поле наследует значение движка или подготовленной конфигурации.
- Три стартовых пресета: **С запасом памяти** (32K), **Несколько клиентов** (32K и ограниченный RAM-кэш), **Длинный контекст** (128K). До применения видны изменения; пресет меняет только черновик.
- Исправлены диапазоны PolyStrata, наследование sampling и отображение native defaults Strata. Существующие значения профилей не заменяются при открытии.
- Сохранены импорт/экспорт, копии профилей, vision, установка внешних движков, RAM-сторож, журнал и мониторинг. Есть поиск, избранное, клавиатурное управление и узкая компоновка.
- Control управляет запуском и настройками. Встроенного чата и Harness/Coding Agent нет. Страницу сервера можно открыть отдельным переходом.

## Проверка и состав

На Windows с Ryzen 9 5950X, 32 ГиБ RAM и RTX 4080 проверены версия движка, доступ к GPU, создание контекста новой cuBLAS, загрузка KQ-библиотеки и ответы текущего API в режиме lazy. Все 92 теста Control проходят; браузерный сценарий проверяет пресеты, профили, импорт/экспорт, клавиатуру и окно 390 px. Дополнительные проверки сборщика покрывают границы пакета и формат метаданных vision.

Полная генерация и обработка изображения на новом движке, установка на чистом ПК и другие GPU не проверялись. Пресеты являются стартовыми вариантами, без новых замеров скорости и качества. Ранее опубликованные замеры Ornith относятся к отдельно указанным сборкам: [подробности](ORNITH-SETUP.md).

Базовые исходники Strata: `7695859aa13afb248bdb4d36f9b2e95707db079d`. В сборщик добавлена небольшая поправка установщика для чтения `vision_archs` как списка либо строки: новый официальный пакет записывает `75;86;89;120`. Нативные CUDA/HIP/SYCL исходники сохранены. Компонент движка имеет собственную версию 0.1.48; данные о происхождении находятся в [UPSTREAM.json](UPSTREAM.json). Лицензия и уведомления исходного проекта сохранены.

Панель и API используют `127.0.0.1`. Для доступа к API с других устройств требуется API-ключ согласно [инструкции Strata](https://github.com/Niko1221/Strata/blob/main/docs/AI_SETUP.md).
