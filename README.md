## Установка с нуля

1. Скачайте полный ZIP по ссылке выше и распакуйте **всю папку** на диск с достаточным свободным местом.
2. Запустите **INSTALL.bat**. Установщик Strata проверит ПК, подготовит Python и зависимости, получит подходящий движок и поможет выбрать модель. Для скачивания компонентов нужна сеть; модель может занимать десятки гигабайт.
3. После установки откроется **Strata Control**. Выберите профиль, настройте запас RAM/VRAM и нажмите «Запустить».
4. Для следующих запусков используйте **START-CONTROL.bat** или ярлык на рабочем столе.

Можно также скачать репозиторий через **Code → Download ZIP** или клонировать его: корневой `INSTALL.bat` сам распакует включённый полный архив в `.strata-full/` и запустит установщик оттуда. Персональные данные этой установки не попадут в Git.

Установка сама не запускает модель: запуском управляет Control. Повторный вызов `INSTALL.bat` позволяет изменить модель и параметры установки.

### Если модель уже скачана

Передайте штатному установщику свои пути, например:

```bat
INSTALL.bat --family coder --model IQ1_M --gguf-dir "D:\Models\Coder\IQ1_M" --models-dir "D:\Models\Coder" --data-dir "D:\Strata-data"
```

Это пример для Coder IQ1_M; выбирайте вариант под RAM своего ПК. Полная процедура находится внутри архива: `Strata/docs/AI_SETUP.md`.

## Control

Оформление в духе Codex Evergreen; запуск, остановка, перезапуск, веб-интерфейс и журнал. Можно менять контекст, KV-кэш, resident KV, spec decoding, expert cache, vision/mmproj, аргументы движка и переменные окружения.

На вкладке «Память ПК» задаётся запас VRAM и RAM; 1 ГБ = 1024 МиБ. VRAM учитывается при выборе автоматического кэша. Резерв RAM ограничивает кэш экспертов; наблюдатель останавливает запущенный сервер, если доступной RAM меньше резерва три проверки подряд. Он работает и после закрытия окна. Нулевая RAM отключает эту защиту. Это не гарантия от аппаратных сбоев или ошибок драйвера.

Встроенный интерфейс открывается через **http://localhost:8080/**; порт берётся из активного профиля. Адрес `localhost` позволяет обойти старое браузерное хранилище другой программы на `127.0.0.1`, сохранив старые данные. Сервер доступен только локально.
